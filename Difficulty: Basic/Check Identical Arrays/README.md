# Check if Arrays are Equal

## Problem Description

Given two integer arrays `a[]` and `b[]`, return `true` if both the arrays contain the same elements in the same order. Otherwise, return `false`.

---

## Examples

### Example 1
- **Input:** `a[] = [1, 2, 3, 4]`, `b[] = [4, 3, 2, 1]`
- **Output:** `false`
- **Explanation:** Both arrays are not the same as they do not contain elements in the same order.

### Example 2
- **Input:** `a[] = [5, 6, 7, 8, 9]`, `b[] = [5, 6, 7, 8, 9]`
- **Output:** `true`
- **Explanation:** Both arrays are the same as they contain the same elements and in the same order.

---

## Constraints

- $1 \le \text{a.size()}, \text{a}[i], \text{b.size()}, \text{b}[i] \le 10^6$
