# Valid Square

## Problem Description

Given a 2D array `points[]` which represents coordinates of four points in a plane. Find if the four points can form a square or not. Return `true` if they form a square else return `false`.

---

## Examples

### Example 1
- **Input:** `points[] = [[0, 0], [0, 1], [1, 0], [1, 1]]`
- **Output:** `true`
- **Explanation:** These points form a square.

### Example 2
- **Input:** `points[] = [[0, 0], [1, 1], [1, 0], [0, 2]]`
- **Output:** `false`
- **Explanation:** These four points do not form a square.

---

## Constraints

- $0 \le \text{X-coordinate, Y-coordinate} \le 10^5$
