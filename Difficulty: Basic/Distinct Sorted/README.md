# Distinct Elements in Sorted Order

## Problem Description

Given an array `arr[]`, return all distinct elements of the array in sorted (non-decreasing) order.

---

## Examples

### Example 1
- **Input:** `arr[] = [3, 3, 2, 2, 1, 4]`
- **Output:** `1 2 3 4`
- **Explanation:** Removing duplicates and sorting in non-decreasing order gives `1, 2, 3, 4`.

### Example 2
- **Input:** `arr[] = [12, 23, 12, 23, 2]`
- **Output:** `2 12 23`
- **Explanation:** All distinct elements arranged in non-decreasing order are `2, 12, 23`.

---

## Constraints

- $1 \le \text{arr.size()} \le 10^4$
