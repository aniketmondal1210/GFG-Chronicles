# Elements Smaller Than X

## Problem Description

Given an array `arr[]`, return all the elements which are less than a given value `x`. The order of returned smaller elements should be according to their appearance in the input array.

---

## Examples

### Example 1
- **Input:** `arr[] = [54, 43, 2, 1, 5]`, `x = 7`
- **Output:** `[2, 1, 5]`
- **Explanation:** `2`, `1`, and `5` are smaller than `7`.

### Example 2
- **Input:** `arr[] = [324, 5, 2, 2, 3]`, `x = 3`
- **Output:** `[2, 2]`
- **Explanation:** `2` and `2` are smaller than `3`.

---

## Constraints

- $1 \le \text{arr.size()} \le 10^5$
