# Distinct Digits in an Array

## Problem Statement

Given an array `arr[]` of positive integers, find all the **distinct digits** that appear in the elements of the array.

Return the digits in **sorted** order.

---

## Example 1

**Input:**

```text
arr[] = [131, 11, 48]
```

**Output:**

```text
[1, 3, 4, 8]
```

**Explanation:**

The distinct digits appearing in the elements of the array are:

```text
1, 3, 4, 8
```

Therefore, the sorted result is:

```text
[1, 3, 4, 8]
```

---

## Example 2

**Input:**

```text
arr[] = [111, 222, 333, 4444, 666]
```

**Output:**

```text
[1, 2, 3, 4, 6]
```

**Explanation:**

The distinct digits appearing in the array are:

```text
1, 2, 3, 4, 6
```

Therefore, the sorted result is:

```text
[1, 2, 3, 4, 6]
```

---

## Constraints

```text
1 <= arr.size() <= 10^5
1 <= arr[i] <= 10^9
```
