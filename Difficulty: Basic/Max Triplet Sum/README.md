# Maximum Triplet Sum

Given an array `arr`, find the maximum possible sum of any three elements in the array.

## Examples

### Example 1

```text
Input: arr[] = [4, 2, 7, 9]
Output: 20
Explanation: Max triplet sum is 4 + 7 + 9 = 20
```

### Example 2

```text
Input: arr[] = [1, 0, 8, 6, 4, 2]
Output: 18
Explanation: Max triplet sum is 8 + 6 + 4 = 18
```

### Example 3

```text
Input: arr[] = [2, 2, 1, 1]
Output: 5
Explanation: Max triplet sum is 2 + 2 + 1 = 5
```

## Constraints

- `3 ≤ arr.size() ≤ 10^6`
- `-10^5 ≤ arr[i] ≤ 10^5`
