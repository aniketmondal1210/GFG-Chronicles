# Find Power of a Number using Recursion (n^p)

## Problem Description

Given two integers `n` and `p`, calculate $n^p$ ($n$ raised to the power of $p$).

---

## Examples

### Example 1
- **Input:** `n = 9`, `p = 9`
- **Output:** `387420489`
- **Explanation:** $9^9 = 387420489$.

### Example 2
- **Input:** `n = 2`, `p = 9`
- **Output:** `512`
- **Explanation:** $2^9 = 512$.

---

## Constraints

- $1 \le n \le 10$
- $0 \le p \le 9$
