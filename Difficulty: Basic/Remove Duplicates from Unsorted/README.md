# Remove Duplicates Preserving Order

## Problem Description

Given an integer array `arr[]`, remove all duplicate elements while retaining the relative order of their **first appearance**.

---

## Examples

### Example 1
- **Input:** `arr[] = [1, 2, 3, 1, 4, 2]`
- **Output:** `[1, 2, 3, 4]`
- **Explanation:** `1` and `2` appear multiple times. Keeping their first occurrences produces `[1, 2, 3, 4]`.

### Example 2
- **Input:** `arr[] = [1, 2, 3, 4]`
- **Output:** `[1, 2, 3, 4]`
- **Explanation:** There are no duplicate elements.

---

## Constraints

- $1 \le \text{arr.size()} \le 10^6$
- $1 \le \text{arr}[i] \le 10^5$
