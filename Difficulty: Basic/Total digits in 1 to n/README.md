# Total Digits From 1 to N

## Problem Description

Given an integer $n$, count the total number of digits required to write all numbers from $1$ to $n$.

---

## Examples

### Example 1
- **Input:** `n = 13`
- **Output:** `17`
- **Explanation:** 
  - Numbers $1$ to $9$ are 1-digit numbers $\rightarrow 9 \times 1 = 9$ digits.
  - Numbers $10$ to $13$ are 2-digit numbers $\rightarrow 4 \times 2 = 8$ digits.
  - Total digits $= 9 + 8 = 17$.

### Example 2
- **Input:** `n = 4`
- **Output:** `4`
- **Explanation:** 
  - Numbers $1$ to $4$ are 1-digit numbers $\rightarrow 4 \times 1 = 4$ digits.

---

## Constraints

- $1 \le n \le 10^5$
