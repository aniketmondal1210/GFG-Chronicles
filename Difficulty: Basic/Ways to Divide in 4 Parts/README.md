# Sum of Four Positive Integers

## Problem Description

Given a positive integer `n`, count the number of ways to represent `n` as the sum of four positive integers:
- $a + b + c + d = n$
- where $a > 0, b > 0, c > 0, d > 0$

Return the total number of such representations.

---

## Examples

### Example 1
- **Input:** `n = 5`
- **Output:** `1`
- **Explanation:** The only possible representation is $1 + 1 + 1 + 2 = 5$.

### Example 2
- **Input:** `n = 41`
- **Output:** `511`
- **Explanation:** There are 511 different ways to represent 41 as the sum of four positive integers.

---

## Constraints

- $0 \le n \le 100$
