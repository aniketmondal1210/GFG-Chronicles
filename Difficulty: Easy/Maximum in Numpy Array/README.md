# Find Maximum Element in a 1D NumPy Array

## Problem Description

Given a 1-dimensional NumPy array `arr` of size $n$, find the **maximum element** present in the array.

---

## Examples

### Example 1
- **Input:** `arr = np.array([1, 3, 7, 9, 5])`
- **Output:** `9`
- **Explanation:** The maximum element in the array is $9$.

### Example 2
- **Input:** `arr = np.array([-8, -2, -15, -1, -10])`
- **Output:** `-1`
- **Explanation:** Among all negative elements in the array, $-1$ is the maximum element.
