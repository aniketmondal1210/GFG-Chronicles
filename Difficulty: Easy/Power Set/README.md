# Power Set (Generate All Possible Substrings)

## Problem Description

Given a string `s`, return the power set (in any order) containing all possible subsequences of the string.

---

## Examples

### Example 1
- **Input:** `s = "a"`
- **Output:** `["", "a"]`
- **Explanation:** The empty string and `"a"` are the only possible subsets.

### Example 2
- **Input:** `s = "abc"`
- **Output:** `["", "a", "ab", "abc", "ac", "b", "bc", "c"]`
- **Explanation:** All possible subsequences of `"abc"` generated in lexicographical order.

---

## Constraints

- $1 \le \text{s.size()} \le 10$
