# Recursive Sum from 1 to N

## Problem Description

Given an integer `n`, compute the sum of numbers from $1$ to $n$ using a **recursive approach**.

---

## Examples

### Example 1
- **Input:** `n = 5`
- **Output:** `15`
- **Explanation:** $1 + 2 + 3 + 4 + 5 = 15$.

### Example 2
- **Input:** `n = 4`
- **Output:** `10`
- **Explanation:** $1 + 2 + 3 + 4 = 10$.

---

## Constraints

- $0 \le n \le 100$
