# Reverse Bits

## Problem Statement

Reverse the bits of a given non-negative integer **n** and return the number obtained after reversal. No leading zeros are to be considered during reversal.

## Examples

### Example 1

**Input:**
```text
n = 11
```

**Output:**
```text
13
```

**Explanation:**
```text
(11)₁₀ = (1011)₂
```

After reversing the bits:
```text
(1101)₂ = (13)₁₀
```

### Example 2

**Input:**
```text
n = 10
```

**Output:**
```text
5
```

**Explanation:**
```text
(10)₁₀ = (1010)₂
```

After reversing the bits:
```text
(0101)₂ = (101)₂ = (5)₁₀
```

## Constraints

- `1 ≤ n ≤ 10⁹`
