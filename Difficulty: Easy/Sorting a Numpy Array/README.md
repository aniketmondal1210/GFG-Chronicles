# Sort 1D NumPy Array in Ascending Order

## Problem Description

Given a 1-dimensional NumPy array `arr`, sort its elements in **ascending order**.

---

## Examples

### Example 1
- **Input:** `array = np.array([3, 1, 4, 2])`
- **Output:** `array([1, 2, 3, 4])`
- **Explanation:** The array `[3, 1, 4, 2]` sorted in ascending order becomes `[1, 2, 3, 4]`.

### Example 2
- **Input:** `array = np.array([10, 5, 8, 1])`
- **Output:** `array([1, 5, 8, 10])`
- **Explanation:** The array `[10, 5, 8, 1]` sorted in ascending order becomes `[1, 5, 8, 10]`.
