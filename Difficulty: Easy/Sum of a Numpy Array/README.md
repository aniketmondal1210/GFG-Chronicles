# Sum of Elements in a 1D NumPy Array

## Problem Description

Given a 1-dimensional NumPy array `arr` of size $n$, find the **sum of all elements** present in the array.

---

## Examples

### Example 1
- **Input:** `arr = np.array([1, 2, 3, 4, 5])`
- **Output:** `15`
- **Explanation:** 
  $$\text{Sum} = 1 + 2 + 3 + 4 + 5 = 15$$

### Example 2
- **Input:** `arr = np.array([10, 20, 30])`
- **Output:** `60`
- **Explanation:** 
  $$\text{Sum} = 10 + 20 + 30 = 60$$
