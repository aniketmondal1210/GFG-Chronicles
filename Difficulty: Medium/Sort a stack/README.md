# Sort a Stack

## Problem Description

Given a stack of integers `st[]`, sort the stack in ascending order such that the smallest element is at the bottom and the largest element is at the top.

---

## Examples

### Example 1
- **Input:** `st[] = [41, 3, 32, 2, 11]` (rightmost element represents the top)
- **Output:** `[41, 32, 11, 3, 2]`
- **Explanation:** After sorting recursively, the smallest element (`2`) is at the bottom and the largest element (`41`) is at the top of the stack.

### Example 2
- **Input:** `st[] = [3, 2, 1]`
- **Output:** `[3, 2, 1]`
- **Explanation:** The stack is already sorted in ascending order (top is largest).

---

## Constraints

- $1 \le 	ext{st.size()}, 	ext{st}[i] \le 10^3$
