# Two Numbers with Odd Occurrences

## Problem Description

Given an unsorted array `arr` of positive integers, all numbers appear an **even number of times** except for **two numbers** which appear an **odd number of times**.

Find these two numbers and return them in **decreasing order**.

---

## Examples

### Example 1
- **Input:** `arr = [4, 2, 4, 5, 2, 3, 3, 1]`
- **Output:** `[5, 1]`
- **Explanation:** `5` and `1` appear once (odd number of times), while `4`, `2`, and `3` each appear twice (even number of times).

### Example 2
- **Input:** `arr = [1, 7, 5, 7, 5, 4, 7, 4]`
- **Output:** `[7, 1]`
- **Explanation:** `7` appears 3 times and `1` appears once (both odd), while `5` and `4` appear twice (even).

---

## Constraints

- $2 \le \text{arr.size()} \le 10^6$
- $1 \le \text{arr}[i] \le 10^7$
